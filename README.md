# 보글 BOGLE

### 상상이 보글보글, 친구가 되다

보글은 **그림과 사진 속 상상을 나만의 AI 캐릭터 친구로 만드는 아이패드 앱**입니다.
캐릭터의 이름·성격·말투를 정하고, 대화와 움직임을 통해 나만의 친구를 만날 수 있습니다.

## 주요 기능

- **캐릭터 생성** — 그림이나 사진의 특징을 살린 투명 배경의 2D 캐릭터를 생성합니다.
- **나만의 친구 설정** — 이름·성격·좋아하는 것·말투를 설정하고 보관함에서 관리합니다.
- **캐릭터와 대화** — 친구 설정과 최근 대화 맥락을 참고해 답변하며, 입력과 답변의 유해성을 검사합니다.
- **표정과 움직임** — AI가 분석한 얼굴 좌표와 Flutter 애니메이션을 결합해 눈 깜빡임·입 움직임·뛰기 등을 표현합니다.
- **전용 배경 생성** — 캐릭터의 색과 형태를 참고해 창밖 풍경을 만들고, 시간대에 따라 색조를 바꿉니다.

## 기술 스택

| 영역 | 기술 | 역할 |
| --- | --- | --- |
| 앱 | Flutter · Dart | 아이패드 UI, 그림판, 캐릭터 애니메이션 |
| 백엔드 | Python · FastAPI · Uvicorn | API, 권한 확인, 백그라운드 생성 작업 처리 |
| 데이터·인증 | Supabase PostgreSQL · Auth | 친구·대화·작업 상태 저장, 토큰 인증 |
| 파일 저장 | Supabase Storage | 이미지 비공개 보관 및 만료되는 서명 URL 제공 |
| AI 연동 | OpenRouter | 캐릭터·배경 이미지 생성, 얼굴 좌표 분석, 대화 생성 |
| 안전성 검사 | OpenAI Moderation | 사용자 입력과 AI 답변의 유해성 검사 |
| 배포·협업 | Render · GitHub Actions | 백엔드 배포, 코드 검사 및 배포 연동 |

## 시연 범위

현재는 **시연용 계정으로 자동 인증**하며, 일반 사용자를 위한 회원가입·로그인 화면은 제공하지 않습니다.
인형 주문은 시연용 UI이며 실제 결제·제작·배송은 연동되어 있지 않습니다.
Render 배포는 프로젝트 시연에 사용했으며, 현재 공개 서버 운영을 보장하지 않습니다.

실행 방법은 [앱 README](frontend/README.md), [서버 README](server/README.md), [Render 배포 가이드](docs/render-deploy.md)를 참고하세요.
