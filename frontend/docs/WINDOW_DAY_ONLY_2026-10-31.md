# 창밖 배경 한 장으로 낮·밤 표현

프론트 release / 개인 백엔드 main. 팀 백엔드는 수정하지 않는다.

- 개인 서버는 캐릭터 생성 성공 직후 낮 배경을 미리 예약한다. 배경 AI 호출은 낮 한 번이고, 밤 이미지 생성은 제거했다. 생성 결과는 PNG 2048×576으로 검증·저장 후 즉시 게시한다.
- 친구 저장 후 소개 화면이 나오는 동안 선택 서비스의 배경 다운로드를 시작한다. 집 화면도 같은 폴링·다운로드를 공유한다. 실패해도 친구 저장·소개·집 입장을 막지 않는다.
- 새 응답의 night=null을 허용하며, 낮 파일 하나로 캐시·재실행·오프라인 표시가 가능하다. 기존 낮·밤 응답과 캐시도 유지한다.
- 기기 시간에 맞춰 창밖에만 아침의 따뜻한 색, 저녁의 분홍·보라, 밤의 청보라색을 보정한다. 주간 색은 원본을 유지한다. 700ms 전환과 모션 줄이기를 지원한다. 기존 별도 밤 그림은 중복 보정하지 않는다.
- 진행 중 다운로드와 집 입장이 중복 요청하지 않으며, 친구 삭제 시 진행 결과를 무효화하고 파일 저장·삭제를 직렬화한다.
- 배경이 아직 준비되지 않았다면 기본 배경과 기존 진행 안내를 표시한다. 외부 AI 응답 속도는 통제할 수 없으므로 집 입장 전 완성은 보장하지 않는다. 실제 AI 키 없이 모의 결과로 검증한다.

배포: 새 앱을 먼저 반영한 뒤 개인 DB에 20261031000400_window_day_only.sql을 추가 적용하고 새 서버를 배포한다. 기존 마이그레이션은 수정하지 않았다. 원격 DB/서버 배포는 수행하지 않았다.

검증 결과:

- Flutter 전체 638개 통과, 조건부 3개 건너뜀. flutter analyze 이상 없음. 저장 직후 미리 받기가 완료되지 않아도 친구 생성이 끝나는 API 테스트 27개 통과.
- 개인 백엔드 실제 임시 PostgreSQL로 전체 472개 통과, Ruff lint·format 통과. 낮 한 번 호출·읽기 검증 실패·이전 야간 데이터 호환·저장된 친구 우선 처리·삭제 후 늦은 결과 차단을 확인했다.
- iPad Pro 12.9 시뮬레이터 및 유선 iPad (78)에서 메모리 저장소로 자동 검증: 중복 생성 POST 0회, PNG 다운로드 1회, 진행 안내 표시·해제, 낮·저녁·밤 전환 통과. artifacts/window-pending/verification.json 및 화면 캡처 참고.
- USB 자동 연결은 Flutter 내장 iproxy의 아키텍처 문제로 실패했으나, 이미 설치된 ARM iproxy로 전달해 기존 테스트 앱에 연결하여 통과했다. Flutter SDK와 시스템 설정은 변경하지 않았다.
- 최종 lib/main.dart 일반 릴리스로 실제 iPad를 업데이트 설치·실행했다. 기존 저장 파일 25개가 테스트 전후와 릴리스 설치·실행 후 모두 바이트 동일했다. 앱 삭제·데이터 초기화를 하지 않았다. 시뮬레이터도 일반 앱으로 복원했다.
- 백엔드 큐는 저장된 친구의 대기 배경을 우선한다. 로그의 이미지 수신·게시 경과 시간으로 실제 키를 연결한 뒤 병목을 측정할 수 있다.
