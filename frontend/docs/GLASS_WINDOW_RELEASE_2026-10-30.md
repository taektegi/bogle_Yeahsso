# 주문 미리보기 대비와 창문 배경 연동 — 2026-10-30

## 반영 내용

주문 화면의 흰 원형 배경을 부드러운 색면·가는 밝은 테두리·은은한 반사와 그림자가 있는 표면으로 교체했다. Apple Liquid Glass의 깊이감을 참고한 Flutter 디자인이며 네이티브 `glassEffect` 구현이라고 부르지 않는다. Apple은 콘텐츠 영역에는 일반 소재를 권장하므로, 캐릭터 그림 자체에 굴절·블러·반투명 효과를 넣지 않았다.

`CharacterPreviewSurface`는 캐릭터 실제 픽셀의 팔레트와 투명도 분석을 재사용해 원색과 구분되는 바탕을 고른다. 흰 꽃잎·검은 몸통·여러 색 생성 캐릭터에도 같은 경로를 쓴다. 투명 여백의 크롭만 유지하고 흰색을 지우거나 색·알파를 변경하지 않는다. 높은 대비 설정에서는 반사 그라데이션을 없애고 불투명 색면과 선명한 테두리를 쓴다.

개인 백엔드의 `/v1/characters/{id}/window-view`에 `ApiWindowViews`를 연결했다. 원격 UUID 친구만 지원하고, 내장 친구는 각자 기존 배경을 유지한다. 집을 처음 열 때 missing이면 한 번 생성 요청하고, 진행 상태를 조회한다. 실패한 작업은 자동으로 유료 재생성하지 않는다. 집의 풍경 버튼에서 명시적으로 다시 시도할 수 있다. 이전 풍경이 있을 때 재생성은 확인 창을 거친다.

완성된 2048×576 낮·밤 PNG를 모두 실제 디코딩한 뒤 임시 파일→이름 변경→캐시 포인터 저장 순서로 게시한다. 만료 URL 대신 파일 이름을 보존하며, 앱 컨테이너 이동·오프라인에서도 사용할 수 있다. 실패하면 기존 풍경을 유지하고 집·대화·간식을 계속 사용할 수 있다. 집을 나가면 추가 폴링을 멈춘다. 친구 삭제의 되돌리기 시간이 지나면 배경 캐시도 정리한다.

배경 프롬프트에는 캐릭터 외형 우선, 평면 색면, 낮은 디테일, 창틀·등장인물 제외, 창문 안전 영역을 추가했다. 밤은 캐릭터를 새로 해석하는 대신 검증한 낮 원본을 참고해 조명만 바꾸도록 했다. 지원하는 21:9 원본에서 낮·밤에 동일한 중앙 크롭을 적용한다. 실제 PNG·불투명도·크기·빈 결과를 검사하고, Storage 읽기 검증을 마친 쌍만 게시한다.

기존 내장 민들레 배경은 꽃과 풀의 세부 묘사·명암이 많아 캐릭터보다 장식이 강해 보인다. 새 프롬프트는 이 부분을 줄이는 방향이다. 다만 **현재 로컬 백엔드에 AI 키·DB 연결이 없으며, 사용자 지정 모의 검증 범위를 유지했으므로 새 실제 AI 결과의 화질·화풍은 미검증**이다. PNG 검사 통과만으로 캐릭터에 어울리는 풍경, 낮·밤 구도 일치, 적당한 밤 밝기가 보장되지는 않는다. 다음 실제 호출에서는 창틀을 씌운 낮·밤 한 쌍을 비교하고, 필요하면 검수한 스타일 예시를 참조 이미지에 추가하는 방식이 적절하다. 품질 미달 때 자동 반복 생성하는 방식은 권하지 않는다.

원격 DB 마이그레이션·서버 배포는 실행하지 않았다. 배포 시 DB 마이그레이션 후 서버를 업데이트해야 한다. 현재 일반 앱은 원래 빌드 설정대로 동작하며 서버 연결 설정이 없는 경우 내장 배경을 쓴다.
