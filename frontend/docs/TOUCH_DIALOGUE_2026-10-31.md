# 캐릭터 터치 반응 문구 개선

작업 브랜치: release.

- 현재 말투 4종 × 편한 말/공손한 말 각각 터치 반응 16개. 어미만 변경하지 않고 말투별 내용과 리듬을 구분했다.
- 기존 반말·해요체·지요체는 각각 17개를 제공한다. 기존 캐릭터 저장 설정은 바꾸지 않는다.
- 캐릭터 ID와 말투별로 문구 인덱스를 비복원 추출한다. 한 바퀴가 끝나기 전에는 같은 문구를 뽑지 않으며, 다음 바퀴의 첫 문구는 직전 문구와 다르게 선택한다.
- 초대 손님의 호출처럼 FriendTalk 객체를 매번 새로 만들어도 같은 캐릭터의 순서는 유지한다. 방을 나갔다 들어와도 앱 실행 중에는 유지한다.
- 순서는 기기에 영구 저장하지 않으며 앱을 완전히 다시 시작하면 새 순서로 시작한다. 최근 128개 캐릭터/말투 조합만 기억한다.
- 터치 반응 선택만 변경했다. 채팅·간식·인사·수면 안내 선택 방식과 모션은 유지한다. 외부 AI 호출은 필요하지 않다.

검증: 현재 8개 말투 조합과 기존 4개 표기에서 각각 4회 순환하며 중복·경계 연속 반복·템플릿 잔여물을 검사했다. 말투별 문장 목록의 차이와 JSON/생성 Dart 사전 동기화도 검증했다.

전체 Flutter 테스트 602개 통과, 조건부 3개 건너뜀. Flutter analyze 이상 없음. iPad Pro 12.9 시뮬레이터 빌드·실행·화면 확인 완료. iPad (78)에 일반 main.dart 릴리스 업데이트 설치·실행 완료. 업데이트 전후 기존 앱 저장 파일 17개의 바이트가 모두 동일했다.
