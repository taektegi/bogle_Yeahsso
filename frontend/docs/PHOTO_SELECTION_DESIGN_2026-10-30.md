# 사진 편집·대상 선택 디자인 정리

기준: frontend release. 백엔드와 사진 전처리 네이티브 알고리즘은 변경하지 않는다.

## 근거

- 기존 Figma: https://www.figma.com/design/bwWLmNFUlLdF4TTO6QlYR7?node-id=489-2142
- 같은 섹션의 편집 가능 프레임 585:2381도 MCP로 확인했다.
  제목/주요 행동은 YANGJIN Regular, UI는 Pretendard Bold,
  크림 #FFFEEE, 로고 #8BA2FF, 본문 #333333을 기준으로 팝업 크기에 맞춰 적용했다.
  사진 선택 기능에 맞춘 새 배치이며 Figma의 캐릭터 설정 화면을 그대로 복제한 것은 아니다.
- 웹 조사: https://lucide.dev/icons/scan, https://lucide.dev/icons/crop,
  https://lucide.dev/icons/rotate-cw, https://lucide.dev/license.
- Lucide 원본 SVG 6개(scan, crop, rotate-cw, sliders-horizontal, undo-2, x)를
  assets/icons/photo에 저장했다. 배포 라이선스 전체도 같은 경로에 포함했다.
  새 패키지 의존성이나 런타임 외부 이미지 요청은 추가하지 않았다.

## 변경

- 마술봉·반짝이·아이콘 배지를 제거하고 24px/2px 선형 아이콘으로 통일했다.
- 돌리기/자르기/선명하게는 같은 너비·높이·모서리·타이포그래피로 맞췄다.
  대상 선택은 사진 아래의 독립적인 진입 영역으로 분리하고 원본 복원은 보조 행동으로 둔다.
- 대상 선택 팝업의 큰 장식 헤더를 없애고 사진/안내를 나란히 배치한다.
  좁거나 큰 글자 환경에서는 사진을 먼저 보여주고 스크롤바로 아래 옵션을 안내한다.
- 주 행동은 하단 한 곳에서 ‘정리해 보기 → 정리한 사진 사용’으로 전환한다.
  원본 비교·대상 다시 고르기·원본 유지/닫기는 그대로 제공한다.
- 제목과 주요 버튼은 앱의 양진체, 안내·선택지는 Pretendard를 명시한다.
- 선택 마커를 실제 이미지의 정규화 좌표에서 그려 화면 크기 변경에도 위치를 유지한다.
- 팝업을 고르는 동안 뒤쪽 제출 버튼이 계속 회전하던 불필요한 진행 표시를 없앴다.
  변환·제출 처리 잠금과 팝업 내부 네이티브 처리 잠금은 유지한다.
