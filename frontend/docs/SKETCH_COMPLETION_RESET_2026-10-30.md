# 생성 완료 후 스케치북 초기화

캐릭터 생성 결과를 받고 설정 화면으로 이동할 때, 해당 생성에 사용한 그림의 자동 저장 초안을 소비하도록 수정했다. 기존에는 그림이 계속 저장되어 다음 스케치북에도 복원됐다.

- 성공한 그림의 선과 undo/redo 기록, 확대·이동 위치를 초기화한다. 펜·색·종이·왼손잡이 등 사용 설정과 생성 결과 이미지는 유지한다.
- 요청 시작이나 애니메이션 종료만으로 지우지 않는다. 실제 생성 결과가 준비되고 결과 화면으로 넘어갈 때만 초기화한다.
- 실패·취소·취소 후 늦은 응답, 사진으로 만든 캐릭터는 그리기 초안을 지우지 않는다.
- 기기 내부 초안 식별자로 제출한 그림을 구분한다. 생성 중 더 그린 새 그림은 보존하고, 앱을 다시 열어 생성 작업을 이어받을 때도 제출한 초안만 초기화한다. 식별자는 AI 요청에 보내지 않는다. 기존 문자열 형식의 미완료 작업 저장값도 읽는다.
- 생성 설정 질문·화면 디자인·백엔드 API는 변경하지 않았다.

검증: `flutter analyze` 통과. 관련 테스트 52개와 전체 테스트 442개 통과(기존 skip 2개). 그림의 즉시·재시작 후 초기화, 되돌리기로 복구되지 않음, 설정 보존, 새 그림 보호, 실패·취소·사진 보존, 재개 작업의 초안 식별자 전달을 확인했다.

실제 iPad 테스트는 메모리 저장소·모의 생성으로 그리기 → 생성 대기 → 결과 받기 → 홈 → 스케치북 다시 열기를 검증한다. 테스트 전 앱 데이터 전체를 `/tmp/bogle-sketch-reset-backup-20261030`에 백업했고 `--keep-app-running`으로 실행한다. 캡처와 결과는 `artifacts/sketch-completion/`에 저장한다.

실기기 첫 실행은 기기 잠금으로 차단되었다(CoreDevice Locked). 자동 테스트 앱을 설치했지만 UI 검증은 아직 완료하지 못했다. 일반 릴리스 빌드로 최종 업데이트하며, 기기 반영 결과는 별도로 확인한다.

최종 일반 릴리스(`lib/main.dart`, 46.0MB)를 실제 iPad에 기존 앱 삭제 없이 업데이트 설치했다. 저장 파일 5개의 SHA-256이 설치 전 백업과 일치했다. 일반 앱 실행도 다시 시도했지만 기기 잠금으로 차단되어, 실기기 실행·UI 검증은 미완료다. 테스트용 포트 연결은 종료했다.
