# 초대 카펫 모션과 한국어 대사 개선 — 2026-10-30

## 카펫

초대하면 기존 카펫 그림 전체가 가로로 늘어나 테두리·장식 점까지 변형되고, 450ms 안에 확장되던 상태였다.

- 확장·복귀를 800ms 사인 곡선으로 조절해 출발·정지를 부드럽게 했다. 주인의 자리 이동과 같은 진행 값을 공유한다.
- 카펫을 매 프레임 실제 크기에 맞춰 다시 그린다. 방의 축척만 균등 적용하므로 테두리 두께·장식 점의 크기는 가로 폭과 무관하게 일정하다. 장식 개수도 고정해 도중에 점이 나타나거나 사라지지 않는다.
- 가로 중심과 바닥 쪽 뒤편 모서리는 유지한다. 폭이 늘면서 깊이만 100→108 단위로 조금 늘어 바닥에서 떠 보이지 않게 했다. 캐릭터 발 위치는 바꾸지 않았다.
- 손님 퇴장 후 같은 곡선으로 원래 크기로 복귀한다. 동작 줄이기 설정에서는 즉시 전환한다.

## 한국어

- 받침에 맞게 `밤이에요`, `사과예요`, `밤이라니`, `도토리라니`, `구름이`, `사과를` 등을 조합한다. 사용자가 입력한 이름·취향은 다시 템플릿으로 해석하지 않는다.
- 명시한 반말은 다정한 성격 설명보다 우선한다. `존댓말`, `공손`, `정중` 설명도 해요체로 인식한다. 반말·해요체·지요체 문장을 각각 다듬었다.
- 손님은 방문객 전용 인사로 초대에 답한다. 손님이 “우리 집에 와 줘서 기뻐”라고 말하지 않는다.
- 초대 안내의 은/는, 간식 추억의 과/와·을/를을 고쳤다. 예: `네모린과 사과를 나눠 먹었어.`
- “배고파”에 이미 먹었다고 답하던 문제를 고쳤다. 간식 대화와 급여 뒤의 반응을 구분한다. “너를 좋아해”와 “네가 좋아하는 건 뭐야?”도 구분한다.
- 질문·마침표·조용한 말줄임표를 보존한다. 모든 문장에 느낌표나 특정 어미를 덧붙이지 않는다.
- 민들레 소개의 `내가 민들레어서 행복해.`를 `민들레여서 행복해.`로 고쳤다. 저장된 소개도 과거 기본 오타와 정확히 일치할 때만 로딩 시 보정한다. 사용자가 편집한 소개와 과거 대화·추억은 유지한다.
- 개인 백엔드에도 동일한 대체 대사·분류를 적용하고 AI 지침에 맞춤법·조사·일관된 말투를 명시했다. AI 원문을 정규식으로 강제 변환하지 않는다. 원격 서버 배포와 AI 자유 생성 품질 검증은 수행하지 않았다.
