# 말투 선택 간소화 — 2026-10-30

## 디자인 기준

[Figma 489:2142](https://www.figma.com/design/bwWLmNFUlLdF4TTO6QlYR7/?node-id=489-2142)의 짧은 안내, 중앙 캐릭터, 하단 카드와 단일 확인 버튼 구성을 Flutter에 적용했다. 해당 노드는 스크린샷 이미지이므로 이미지를 UI 에셋으로 사용하지 않고 기존 앱 컴포넌트·양진체·Pretendard·색상 토큰으로 구성했다. 참조 이미지는 `artifacts/figma-speech-reference/reference-489-2142.png`에 보관한다.

## 변경

- 생성 화면의 말투를 `담백하게 / 발랄하게 / 이야기하듯 / 로봇처럼` 네 카드로 직접 선택한다. 기존 네 manner 식별자와 백엔드 계약은 유지한다.
- 긴 설명 대신 짧은 예문 한 줄을 표시한다. 선택하면 중앙 캐릭터의 말풍선에 실제 대화 사전의 미리보기를 표시한다.
- 생성 화면에서 `편한 말 / 공손한 말`, `놀이 / 간식 / 응원` 선택란을 제거했다. 새로운 친구의 기본 말끝은 기존 기본값인 편한 말이다. 뒤로 갔다 돌아와도 선택은 유지한다.
- 기존 캐릭터의 8가지 말투 데이터 및 편집에서의 높임말 변경 기능은 유지한다. 저장 데이터 이관이나 서버 변경은 없다.
- 카드 아이콘은 말풍선·웃는 얼굴·책·로봇으로 정리했다. 반짝이 아이콘을 제거하고 앱의 파란색 계열과 일정한 크기로 통일했다. 확인 버튼은 윤곽선 하트를 쓴다.
- 넓은 화면에서는 4개 가로 카드, 작은 화면에서는 2열이다. 실제 글꼴과 텍스트 배율에 따라 카드 높이를 측정하며, 좁은 창·큰 글자에서는 세로 스크롤을 유지한다.

## 검증

- 생성 흐름·저장 결과·네 가지 실제 미리보기·편집의 기존 8조합·복구 회귀 테스트 21개 통과.
- 실제 글꼴 캡처: 1024×768 / 1194×834 / 1366×1024 / 744×600(글자 200%). 참조 이미지와 비교하여 하단 선택 카드와 중앙 캐릭터 배치를 확인했다. 큰 글자에서는 스크롤로 모든 선택과 확인 버튼에 접근한다.
- Flutter analyze 통과.
- iPad Pro 12.9인치 시뮬레이터 일반 앱 빌드·실행·화면 확인.
- 유선 iPad (78)에 `lib/main.dart` 릴리스 빌드·업데이트·실행·화면 캡처 완료. 업데이트 전후 앱 데이터 7개 파일의 내용이 모두 동일했다. 실제 기기에서는 기존 사용자 데이터를 바꾸는 생성 테스트를 수행하지 않았다.
