# 폰트 역할 정리

브랜치: release. 사용자 승인에 따라 기존 양진체/Pretendard 두 글꼴의 역할만 정리한다.

- 제목·질문·주요 버튼·짧은 캐릭터 말풍선은 양진체를 명시한다.
- 기본 본문은 Pretendard로 설정한다. 입력란·설명·설정 본문·긴 이야기 팝업이 같은 읽기용 글꼴을 사용한다.
- 화면의 withBogleBodyFont는 본문 역할만 바꾸며 제목/버튼용 테마를 다시 덮어쓰지 않는다.
- 기본 AlertDialog에도 제목과 본문 글꼴을 명시하여 작별·수면·스케치북 설정이 공통 팝업과 다른 글꼴을 상속하지 않게 한다.
- 홈 카드·캐릭터 질문·기존 페이지 헤더의 명시된 글꼴을 유지한다. 색상 선택 제목·큰 설정 제목·프로필 버튼·스케치북 주요 동작에도 표시용 역할을 명시한다.
- 수면 시간 휠의 텍스트는 Pretendard를 명시한다. 주문 제작 기간 표기는 양진체에 없는 en dash 대신 `7~10일`을 사용한다.
- 이모지와 운영체제·외부 주소 검색 화면의 고유 글꼴은 플랫폼/서비스 동작을 유지한다. 새 글꼴이나 의존성은 추가하지 않았다.

검증: 실제 상속된 RenderParagraph/EditableText를 통해 화면 제목·본문·버튼·말풍선·입력란 및 기본 팝업의 역할을 확인한다. 실제 글꼴을 로드하는 기존 계정 화면 캡처 검증으로 프로필 편집 화면을 확인했다. `artifacts/account-visual/profile-editor.png`.

- 전체 Flutter 테스트 631개 통과, 조건부 3개 건너뜀. flutter analyze 이상 없음.
- 실제 글꼴 계정 화면 캡처 테스트 통과. iPad Pro 12.9 시뮬레이터 빌드·실행·홈 화면 확인 완료.
- 유선 iPad (78)에 lib/main.dart 일반 릴리스 업데이트 설치·실행·홈 화면 확인 완료. 기존 저장 파일 21개가 업데이트 전후 바이트 동일했다. 앱 삭제나 데이터 초기화는 수행하지 않았다.
