# 프론트 검토 사항 적용 및 사진 도구 정리 — 2026-10-30

작업 브랜치: release. 개인/팀 백엔드는 변경하지 않았다.

## 데이터 복구

FileStore는 정상 JSON을 원자적으로 교체하기 전에 마지막 읽을 수 있는 문서를 `.json.bak`으로 보관한다. 기본 파일이 손상되거나 없어지면 정상 백업으로 읽으며, 둘 다 손상되면 초기 사용자로 취급하지 않고 StoreRecoveryException을 전달한다. 읽을 수 없는 원본 위에 새 기본값을 쓰는 것도 막는다. 캐릭터 저장 문서의 구조가 손상된 경우에도 기본 친구 목록으로 덮어쓰지 않는다. 기존 정상 JSON은 변환 없이 읽는다.

백업은 마지막 정상 저장본이므로 가장 최근 변경 한 번까지 완전히 복원한다고 보장하지 않는다. 기기 분실·앱 삭제에 대비한 외부 백업 기능은 아니다.

## 대화 기록

로컬 기록은 AI 전송 서비스와 분리한 ConversationArchive에 저장한다. 본 기기의 기록이 없을 때만 기존 서버 기록을 불러오며, 가져온 과거 기록도 로컬에 보관한다. 사용자의 말과 집주인의 반응뿐 아니라 손님의 인사·쓰다듬기·간식 반응도 기록한다. 기록 화면은 각 화자의 아바타를 사용하며, 장면 말풍선에 이름 제목을 다시 추가하지 않는다.

- 대화방별 최근 500개 기록을 순서대로 보관한다. 동시 쓰기는 직렬화한다.
- 화자 그림 경로는 앱 업데이트 시 FileStore.relocate로 보정한다.
- 이미 지나간 로컬 대화를 소급 복구할 수는 없다. 이번 업데이트 이후의 기록부터 쌓인다.
- 초대 손님이 삭제되더라도 이전 대화의 화자 스냅샷은 남긴다. 캐릭터 삭제 취소에도 과거 기록을 유지한다.

## 캐시 및 큰 글자

그림 분석·얼굴·리그 캐시를 LRU로 제한했다. PNG 바이트 캐시는 최대 24항목 / 24MiB이며, 큰 항목은 표시 후 캐시에 유지하지 않는다. 메타데이터는 용도별 32~96항목으로 제한한다. 캐릭터 삭제 시 해당 그림 경로의 캐시를 비운다. 이는 앱 전체 메모리 사용량의 상한을 뜻하지 않는다.

채팅 받침의 실제 렌더링 높이를 측정해 장면 배치에 반영하고, 추천 문장 행 높이도 글자 배율에 따라 늘린다. 기존 최대 1.35배 추정치에만 의존하지 않는다.

## 탐색·팝업

상단 알림은 마이페이지에서도 항상 소식 팝업을 연다. 알림 설정은 기존 마이페이지 메뉴에서 접근한다. 알림·캐릭터 편집·일반 설정 팝업은 BogleDialogFrame/Header를 공유한다. 제목 양진체 / 본문 Pretendard, 크림색·파란 구분선·24 모서리·48 이상 닫기 영역을 공통 관리하며, 저장 중 PopScope는 maybePop으로 존중한다. 헤더의 장식 아이콘 배지는 제거했다.

## 사진 확인

돌리기·자르기·선명하게는 같은 폭·높이·20pt 아이콘·일정한 간격을 사용한다. 대상 선택은 같은 글자 크기와 56 이상 높이의 보조 버튼으로 정리하고, 장식 아이콘·화살표·보조 문장을 제거했다. AI 연결 상태를 설명하던 하단의 중복 작은 문구도 제거했다. 사진 정리·원본 복원·생성 기능은 유지한다.
