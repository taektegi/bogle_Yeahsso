# 집 대화 말풍선·입력 영역 개선

- 대화 시 얼굴을 가리지 않도록 옆에 놓이는 말풍선의 꼬리를 본체 하단 모서리에 연결했다.
  본체와 꼬리를 하나의 Path로 그리고 하단을 같은 직선에 맞춘다. 좌우는 동일 윤곽을 반전한다.
  기본 집의 아래로 향하는 말풍선은 유지한다. 옆 꼬리의 끝 위치에 맞게 화자 방향 배치도 보정한다.
- 입력 받침의 최대 폭을 680→760pt, 안쪽 여백을 20/16/20/18pt로 확대했다.
  상단 버튼 아래 12pt, 추천 대화 줄 48pt, 입력칸 위 12pt, 보내기 옆 12pt를 확보했다.
- 키보드 표시 시에는 기존 높이에 가까운 compact 여백으로 전환하여 얼굴·말풍선·키보드가
  겹치지 않도록 한다. 캐릭터 배치 계산도 받침의 늘어난 기본 높이를 반영한다.
