## 수정 내용

- 친구집 상태 조회 실패 시 재시도 안내를 표시한다. 돌봄·추억 저장 실패를 처리해 화면이 계속 동작하며 실패 이유를 알려 준다.
- 대화 답변이 늦게 도착해도 그 사이에 바뀐 돌봄 상태를 유지한다.
- 친구가 없는 주문 화면에서 친구 만들기로 이동했다가 돌아오면 목록을 다시 읽는다.
- 배송지 저장 실패 시 입력한 내용을 보관해 다시 열었을 때 재입력 없이 저장할 수 있다. 주문 내역 조회 실패도 다시 시도할 수 있다.
- 배송지의 이름·연락처를 줄바꿈하고, 확대 글꼴에서 주문 요약·가격·옵션 태그가 넘치지 않도록 보완한다.
- 친구 설정에서 음성 입력 중단을 기다리는 동안 화면이 닫힌 경우 후속 화면 갱신을 중단한다.
- 고객센터와 데이터 보관 안내를 현재 구현에 맞춘다. 완성한 친구·그림·프로필은 기기에 저장되며, 스케치북 초안은 앱 종료 시 초기화된다. 인형 주문이 실제 제작·배송으로 이어지지 않는다는 점을 안내한다.
