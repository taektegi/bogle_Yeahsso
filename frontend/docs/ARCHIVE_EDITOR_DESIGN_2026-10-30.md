- 제목·항목명·말투 카드 제목·저장/취소는 양진체, 실제 입력 내용·설명·글자 수는 Pretendard로 역할을 구분했다.

- 편집용 말투 카드는 장식 아이콘과 중복 소제목을 제거했다. 선택은 파란 테두리·색면과 접근성 selected 상태로 구분한다. 좁거나 큰 글자에서는 카드도 1열이다.
- 기존 말투 데이터는 선택 전까지 유지한다. 4가지 방식·2가지 말끝의 기존 편집 기능과 구형 말투로 되돌리기도 유지한다. 캐릭터 생성 화면의 선택 구조는 바꾸지 않았다.
