# 대화에서 캐릭터 집으로 돌아가기

작은 X 아이콘을 입력창 상단 왼쪽의 `← 집으로 돌아가기` 버튼으로 바꿨다. 크림색 받침에 연한 파란색 버튼을 사용하며 최소 높이는 52pt다. 키보드가 열려 있어도 입력창 위에 보이고, 답변 대기 중이나 친구가 자는 동안에도 누를 수 있다. 폭이 좁거나 글자가 크면 상단 버튼이 줄바꿈된다.

복귀 시 입력 포커스를 해제하고 대화 입력창을 닫는다. 주고받은 이야기와 집 상태는 유지한다. 시스템 뒤로 가기도 대화창부터 닫도록 처리했다. `이전 이야기`의 X도 `대화로 돌아가기` 버튼으로 바꿨다. 커진 입력창 높이를 장면 배치 계산에 반영해 캐릭터·말풍선과 겹치지 않게 했다.

## 확인

- 대화 복귀·기록 유지, 키보드 포커스 해제, 시스템 뒤로 가기, 좁은 폭·큰 글자, 초대한 친구와 대화 배치 등 관련 테스트 51개 통과.
- `flutter analyze`: 문제 없음.
- 연결된 실제 iPad Pro 12.9(5세대), `00008103-001D78463C3B001E`에 `lib/main.dart` 일반 릴리스(46.1MB)를 업데이트 설치하고 실행했다. 실제 Runner 프로세스도 확인했다.
- 앱 삭제·데이터 초기화 없이 설치했다. 실행 후 저장 파일 5개의 SHA-256이 설치 전 백업과 모두 일치했다. UI 동작 검증은 위 Flutter 테스트 기준이며 실제 기기 자동 터치 테스트는 수행하지 않았다.
