# 초대 말풍선과 인사 간격 — 2026-10-30

## 변경

- 두 친구가 있는 집의 장면 말풍선에서 화자 이름 제목을 제거했다. 꼬리와 배치는 기존처럼 말하는 캐릭터를 따라간다. 상대를 부르는 실제 인사말(예: `어서 와, 뚜치!`)은 유지한다.
- SceneSpeech의 크기 측정에서도 이름 제목 공간을 제거했다. 화면 읽기에는 화자 이름을 전달하고, 긴 대사의 페이지 이동·전체 읽기 기능은 유지한다.
- 초대 후 집주인 인사에서 손님 답변까지의 고정 750ms를 문장 길이에 따른 간격으로 변경했다. 공백을 제외한 표시 문자 수를 기준으로 `읽는 시간 = clamp(1800 + 글자 수 × 140, 4000, 8500)ms`, 여기에 650ms의 대화 간격을 더한다. 최소 4.65초, 최대 9.15초다.
- 대기 중에도 집주인 말풍선은 보인다. 사용자가 쓰다듬기·간식·대화·배웅 등 새 행동을 하면 기존 방문/행동 토큰과 조건 검사로 늦은 인사가 새 반응을 덮지 않게 한다. 손님 인사는 다음 행동 전까지 유지한다.

## 웹 조사와 판단

[The Bot Platform 공식 가이드](https://dev.thebotplatform.com/docs/delays)는 메시지 사이에 읽을 간격을 두고 대상 사용자의 읽는 속도에 맞춰 검증하라고 안내한다. 지나치게 긴 지연은 멈춘 것처럼 느껴질 수 있다고도 설명한다.

[NN/g의 대화 UI 연구](https://www.nngroup.com/articles/ai-chatbots-design-guidelines/)는 사용자가 읽는 도중 표시 위치를 강제로 바꾸면 읽던 곳을 다시 찾아야 하는 문제를 지적한다. 이 자료를 근거로 읽는 시간을 보장한 뒤 교대하도록 했다.

위 초 단위 수치는 자료가 제시한 한국어 표준 읽기 속도가 아니다. 보글의 짧은 한글 인사와 아동 사용 흐름에 맞춘 보수적인 제품 설정값이며, 사용자 관찰에 따라 조정할 수 있다. 가짜 AI 입력 지연이나 타이핑 표시를 추가한 것은 아니다.

## 검증

- 초대·배웅·간식·대화·한국어·말풍선 배치 테스트 56개 통과, Flutter analyze 통과.
- 새 회귀 검증: 1초 후에도 집주인 인사 유지, 계산된 간격 직전까지 유지, 이후 손님 답변, 화자 이름 시각 제거·접근성 보존, 쓰다듬기 후 늦은 인사 취소.
- 짧고 긴 문장·공백에 대한 시간 계산 경계 검증. 큰 글자와 각 iPad 크기의 기존 장면 말풍선 배치 검증 유지.
- 실제 글꼴로 집주인·손님 말풍선 캡처 확인. 모의 저장소를 사용해 실제 캐릭터 기록을 변경하지 않았다.
- 시뮬레이터 일반 앱 빌드·실행·화면 확인 완료.
- 유선 iPad (78)에 일반 릴리스 업데이트·실행·화면 캡처 완료. 개발 팀 서명과 업데이트 전후 앱 데이터 8개 파일의 내용이 모두 동일함을 확인했다.
