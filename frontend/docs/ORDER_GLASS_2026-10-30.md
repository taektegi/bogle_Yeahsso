# 주문 캐릭터 미리보기 글래스 — 2026-10-30

## 참조와 적용

[Figma Glass Effect 230:3907](https://www.figma.com/design/bwWLmNFUlLdF4TTO6QlYR7/?node-id=230-3907)를 MCP로 확인했다. 원본은 70×155, radius 100의 무색 투명 프레임이며 GLASS 효과(radius 6, refraction .7, depth 30, light intensity .4, dispersion/splay .2)와 상하 내측 음영을 사용한다. 이미지 에셋은 없는 효과 기반 노드다.

Flutter에서는 기존 원형 캐릭터 슬롯을 유지하고 다음 특성을 적용했다.

- 원형 경계 안에만 sigma 6 배경 흐림을 적용하고, 반투명 가장자리와 얇은 흰 반사광·내측 음영으로 유리 두께를 표현한다. 캐릭터와 문구는 흐리거나 변색하지 않는다.
- 중앙 84% 반경까지는 기존 그림 분석 기반 배경색을 유지한다. 흰 꽃잎 등의 대비가 밝은 반사광 때문에 낮아지지 않도록 한다. 캐릭터별 대표색과 분석 결과를 이용하며 특정 캐릭터 ID 예외는 제거했다.
- 바깥의 단색 사각 배경을 크림·흰색에 섞은 은은한 대표색 그라데이션과 둥근 모서리로 정리했다. 친구 선택과 인형 옵션 단계가 같은 소재를 쓴다.
- 고대비에서는 흐림과 반사광을 끄고 불투명 배경·뚜렷한 테두리를 쓴다.
- Figma의 광학 굴절·색 분산을 그대로 실행하는 것은 아니다. Flutter의 국소 배경 흐림과 정적인 림 페인팅으로 표현한다. 왜곡 셰이더·움직이는 반사·전체 화면 흐림은 사용하지 않는다. 성능 프로파일링 결과를 주장하지 않는다.

## 검증

- 주문·배경 대비 및 시각 검증 테스트 19개 통과, Flutter analyze 통과.
- 실제 글꼴 캡처: 민들레·뭉글이·뽀직뽀직(1366×1024), 민들레 작은 창(744×600), 고대비. PNG 디코딩을 사전 완료한 뒤 캡처했으며 `artifacts/order-glass/`에 저장했다.
- 민들레 중앙 배경과 흰색의 대비 1.7 이상 유지, 원본 이미지 경로 유지, 캐릭터에 ImageFiltered가 적용되지 않음, 고대비에서 BackdropFilter 비활성화 확인.
- 시뮬레이터 일반 앱 빌드·실행·캡처 완료. 실제 AI 생성 이미지의 미적 품질 평가는 이번 검증 범위에 포함하지 않는다.
- 유선 iPad (78)에 일반 릴리스 업데이트·실행·화면 캡처 완료. 개발 팀 서명 확인, 업데이트 전후 앱 데이터 8개 파일의 내용 모두 동일함 확인.
