# Figma 기준 말투 선택 화면

## 디자인 근거

[Figma 489:2142](https://www.figma.com/design/bwWLmNFUlLdF4TTO6QlYR7?node-id=489-2142)를 Figma MCP로 조회했다. 지정 노드는 1366×1024 화면을 담은 이미지다. 같은 섹션의 편집 가능한 설정 프레임 `585:2381`도 조회해 크림색 `#FFFEEE`, 로고색 `#8BA2FF`, 글자색 `#333333`, 양진체·Pretendard와 공통 헤더를 확인했다. Figma 파일은 수정하지 않았다.

원본 화면의 중앙 캐릭터, 하단 흰색 선택 카드, 둥근 확인 버튼과 모서리의 은은한 색감을 적용했다. 3가지 기존 말투를 그대로 복제하는 대신 현재 기능의 네 가지 말하는 느낌과 두 가지 말끝에 맞게 배치했다.

- 캐릭터와 예문 말풍선을 화면 가운데에 둔다.
- 말하는 느낌 네 가지를 하단 가로 카드로 선택한다. 좁은 창에서는 2열로 전환한다.
- 카드 아래 편한 말·공손한 말, 하트 아이콘이 있는 `이 말투로 할래요` 확인 버튼을 둔다. 선택 전에는 비활성 상태도 보인다.
- 놀이·간식·응원 예문은 작은 선택 칩으로 바꾼다. 실제 음성이 없는 기능에 맞춰 안내는 `눌러서 예문을 비교해요.`로 표시한다.
- 큰 글자·작은 창에서는 세로 스크롤을 제공하고 예문이 길어도 캐릭터 공간을 확보한다.

## 기존 코드와 에셋 재사용

`AppTopBar`의 `assets/figma/logo.svg`, `header_icons.svg`, 기존 글꼴과 디자인 토큰을 사용한다. 내려받은 Figma 헤더 아이콘은 로컬 에셋과 동일한 크기(188.62×49.5902)이며, 로고는 기존 컴포넌트에서 높이 55pt로 표시하면 Figma의 88.88×55 비율과 맞는다. 캐릭터는 생성 결과 `GeneratedArt`를 그대로 바인딩한다. 기본 친구는 `character_friend.svg`를 사용한다.

Figma 원본 전체 이미지와 조회에 쓰인 SVG는 검수용 `artifacts/figma-speech-reference/`에만 보관한다. 원본 화면을 앱 배경 이미지로 삽입하지 않았고, 코드나 에셋에 임시 Figma 다운로드 URL을 남기지 않았다. iPad 상태 막대는 Flutter의 기존 OS 처리·SafeArea를 사용한다.

`SpeechStylePicker`는 생성 전용 배치를 옵션으로 제공한다. 보관함의 기존 편집 화면은 기존 격자 배치를 유지한다. 말투 저장 값, 8가지 조합, 예문 및 백엔드 계약은 바꾸지 않았다.

## 검증

- 관련 Flutter 테스트 21개 통과: 이름·성격·좋아하는 것에서 말투로 진행, 8가지 말투 조합·예문·저장, 저장 실패 후 재시도, 기존 친구 편집.
- `flutter analyze`: 문제 없음.
- 실제 앱 폰트로 1024×768, 1194×834, 1366×1024와 744×600·글자 2배를 렌더링해 검수했다. `flutter test test/setup_speech_design_test.dart --dart-define=CAPTURE_SPEECH_DESIGN=true`로 PNG를 재생성할 수 있다.
- 좁은 창·큰 글자에서 기존 공통 상단 바의 `Setting` 글자가 잘리는 현상은 이번 변경 범위 밖으로 기록한다. 말투 본문과 확인 버튼은 스크롤하여 사용할 수 있다. 다른 질문 단계의 큰 글자 문제도 이번 말투 디자인 수정에 섞지 않았다.

## iPad 반영

최종 요청대로 iPad (78), `00008103-001D78463C3B001E`에 유선 연결(`transportType: wired`)로 `lib/main.dart` 일반 릴리스(46.1MB)를 업데이트 설치했다. 설치 후 잠시 연결이 해제됐으나 재연결 후 앱 실행과 실제 Runner 프로세스를 확인했다. 앱을 삭제하거나 데이터를 초기화하지 않았으며, 실행 후 저장 파일 6개의 SHA-256이 설치 전 백업과 모두 일치했다. 실제 기기 자동 터치 테스트는 수행하지 않았고 UI 검수는 위 Flutter 렌더링·동작 테스트 기준이다.
