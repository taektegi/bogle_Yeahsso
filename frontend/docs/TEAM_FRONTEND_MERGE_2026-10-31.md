# 팀 저장소 프론트 통합

개인 프론트 `release`의 `8909e315d85b923f852fae68bbc4b0851a773de1`을 팀 저장소 `main`의 `dae4dd56a3845abb1a5d684315362ffb4e4d73ac` 위에 통합한다. 두 저장소에 공통으로 존재하던 개인 프론트 `5d1b9c7`의 파일들이 팀의 최초 `frontend/` 도입 커밋 `3497c96`과 동일함을 확인하고 이를 기준으로 3자 병합했다.

변경은 `frontend/` 안으로 한정한다. 팀 저장소의 `server/`, `supabase/`, `.github/`, 루트 문서는 변경하지 않는다. 개인 프론트 작업 디렉터리와 개인 백엔드도 수정하지 않는다.

## 반영한 내용

- 파일 손상 복구·작별 후 파일 정리·프로필 복원·부분 동기화 실패 표시·대화 ID 보존.
- 폰트 역할 통일·창밖 배경 진행 안내·낮 한 장 캐시와 시간대 색상 보정·대상 선택 상태 및 재시작 요청 복구.
- 주문 뒤로가기 버튼 배치와 홈 뭉글이 이미지·최종 확대 상태.

## 팀 변경 보존

- 그림 생성 후 얼굴 좌표를 비동기로 받아 저장하는 흐름과 재시작 복구.
- 친구 설정 후 얼굴 분석을 기다리는 기존 로딩 화면.
- 성격 목록을 서버에서 조회하여 코드로 저장하는 흐름. 팀의 기존 표시명과 개인 서버의 새 표시명을 모두 찾도록 병합했다.
- 서버 GIF를 호출하지 않는 팀 앱 내장 모션 설정.
- 삭제 취소 경합 보호와 서명 URL 검증·팀 서버 진단 테스트.

API 계약은 합집합으로 만들지 않는다. `test/contract/openapi.json`은 가져온 개인 서버 계약이고, `team_openapi.json`은 이 팀 서버 `dae4dd5`의 FastAPI에서 생성한 계약이다. 얼굴 분석 지연 응답은 팀 계약으로, 개인 서버 확장 기능은 개인 계약으로 검증한다.

## 팀 백엔드에 아직 없는 기능

- `/window-view`가 없어 서버 생성 배경은 받을 수 없다. 앱은 기존 기본 풍경으로 집·대화·간식을 계속 제공한다.
- `photoMode` 전용 프롬프트 분기는 팀 서버에 없다. 대상 분리 PNG는 일반 사진 경로로 처리되며, 전용 프롬프트는 개인 최신 서버에서만 사용된다.
- 프로필의 bio·interests·profileColor는 팀 서버에 없어 기기 보관은 가능하지만 해당 필드의 서버 복원은 지원되지 않는다.

이 항목을 구현하려고 백엔드나 마이그레이션을 변경하지 않았다. 실 AI 호출·배포 서버 연결은 이번 병합 검증 범위에 포함하지 않는다.

검증: 병합한 프론트의 flutter analyze 통과, 전체 Flutter 테스트 654개 통과·조건부 5개 건너뜀. 팀 서버는 수정하지 않은 상태에서 Ruff lint·format과 실제 임시 PostgreSQL 테스트 471개가 통과했다. 플랫폼 빌드·기기 실행의 최종 결과는 PR 본문에 기록한다.
