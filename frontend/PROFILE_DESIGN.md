## 가로 화면 적용

고정 높이 패널 대신 한 개의 세로 스크롤을 사용한다. 상단 프로필 소개 아래, 넓은 화면에는 친구/주문 영역과 설정 영역을 7:3으로 배치했다. 본문 폭 900 미만 또는 큰 글자 설정에서는 한 열로 전환한다. 콘텐츠 최대 폭은 1400이며 프로필 편집 대화상자는 키보드가 올라와도 스크롤할 수 있다.

크림 배경과 블루 포인트, 원본 사진/로고, 기존 앱의 둥근 제목 글꼴을 유지했다. 섹션 헤더 높이와 카드 여백을 맞추고, 블러는 반복 사용하지 않았다. 화면 전환은 기존 공통 경로를 쓰며 시스템 동작 줄이기를 따른다.

## 동작과 데이터 경계

- 닉네임 검증(공백 불가, 최대 12글자), 프로필 이미지 선택, 저장/취소/실패 피드백.
- 친구 상세, 전체 보관함, 새 친구 만들기 연결. 화면 복귀 시 친구 데이터 새로 조회.
- 예시 주문의 진행/완료 필터, 배송 단계, 주문 상세. 실제 주문·주소·운송장 정보는 생성하지 않는다.
- 알림 선택 저장, FAQ 펼치기, 문의/접근성/앱 데이터 안내.
- `ProfileRepository`와 DTO를 분리했다. 기본 구현은 홈 화면이 소유한 메모리 저장소이며, 재진입 시 유지되지만 앱 재시작 시 초기화된다.
- 실제 로그인, 파일 업로드, 푸시 권한·전송, 결제·주문·배송·고객 문의 API는 연결하지 않았다.
- 로딩/오류/빈 친구/빈 주문/저장 실패 상태를 제공한다.
