# 요구사항 확인 질문 — 3차 (마지막)

2차 답변으로 대부분 정리되었습니다. 남은 것은 3개입니다.

**2차에서 확정된 내용**
- 2주 안에 전체 범위 진행, 품질 기준(테스트·예외 처리)은 낮춤 (CQ1)
- 동의 절차 없이 **시연용 계정만** 사용 — 실제 아동 데이터는 받지 않음 (CQ2)
- 인형 주문 화면은 서버와 연결하지 않음 — 카탈로그·견적·배송지·주문 모두 범위 외 (CQ3)
- Google 로그인 — Supabase Auth Google OAuth (CQ4)
- 기분·배부름·기운·친밀도, 레벨·추억 수 **모두 삭제**. 친구의 집에는 수면 상태(22–06시)만 남음 (CQ5)
- 생성형 대화는 캐릭터 설정을 바꾸지 않음. 설정은 생성 직후 초기 설정 단계에서 객관식으로 확정 (CQ6)
- 쓰다듬기·초대 삭제, 간식은 모션만 남음 (CQ7). 수면 22:00–06:00 모든 친구 고정, 편집 삭제 (CQ8)
- API 서버 Python FastAPI (CQ9), 이미지 생성 OpenAI (CQ10), 결과는 투명 배경 캐릭터 PNG 한 장 (CQ11)
- 대화는 OpenAI + Moderation API로 입력·출력 검사, 실패 시 스크립트 대사로 대체 (CQ12)
- 보안 확장 미적용 (CQ13)

## 모호 1: 초기 설정 단계의 항목과 입력 방식 (CQ6)
현재 앱의 설정 단계는 **이름(직접 입력) → 성격(직접 입력, 30자) → 좋아하는 것(객관식 다중 선택) → 말투(객관식)** 입니다. CQ6 답변의 "객관식으로 캐릭터 성격유형 등의 캐릭터 배경 설정을 확정"은 지금과 다른 방식이라 확인이 필요합니다.

### Clarification Question 1
초기 설정 단계는 어떻게 바뀌나요?

A) 이름만 직접 입력하고, 성격도 **정해진 성격 유형 목록에서 고르는 객관식**으로 바꿈. 좋아하는 것·말투는 지금처럼 객관식

B) A에 더해 **배경 설정 항목(예: 사는 곳, 종족, 특기 등)을 객관식으로 추가**. 항목과 선택지는 기획에서 정함

C) 지금 그대로 유지 (성격은 직접 입력)

X) 기타 ([Answer]: 뒤에 내용을 적어 주세요)

[Answer]: A

### Clarification Question 2
보관함 카드에 보이는 **소개 문구**(`introduction`, 지금은 수정 화면에서 직접 입력, 최대 70자)는 어떻게 할까요?

A) 유지 — 지금처럼 수정 화면에서 직접 입력

B) 초기 설정에서 고른 객관식 답을 바탕으로 **AI가 자동으로 만들어 줌** (수정 화면에서 고칠 수 있음)

C) 삭제

X) 기타 ([Answer]: 뒤에 내용을 적어 주세요)

[Answer]: B

## 모호 2: 대화 기록의 저장과 기억
레벨·추억 수는 삭제되었지만(CQ5), 생성형 대화가 지난 대화를 기억할지는 아직 정해지지 않았습니다. 서버 저장 여부와 AI 비용이 달라집니다.

### Clarification Question 3
대화 기록은 어떻게 할까요?

A) 서버에 저장. 친구의 집에 다시 들어오면 이전 대화가 보이고, AI는 **최근 대화 N개를 기억**해서 답함

B) 서버에 저장하지만, AI는 **이번 방문의 대화만** 기억 (다시 들어오면 이전 대화가 보이기는 함)

C) 저장하지 않음 — 친구의 집 화면에 있는 동안만 유지되고, 나가면 사라짐

X) 기타 ([Answer]: 뒤에 내용을 적어 주세요)

[Answer]: A
