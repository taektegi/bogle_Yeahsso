# 얼굴 분석 예시 자료

FR-10의 Luna 얼굴 분석 요청에 함께 보내는 검수된 예시 6장이다.
운영 코드는 이 폴더만 읽으며 Downloads나 임시 실험 폴더에 의존하지 않는다.

| 파일 | 예시 |
|---|---|
| `016.png` | 정면 하트 캐릭터 |
| `028.png` | 몸과 구분되는 둥근 머리 |
| `dduchi.png` | 왼쪽 옆모습, 실제 입 없음 |
| `021.png` | 토끼의 감긴 눈과 웃는 입 |
| `023.png` | 긴 얼굴과 분홍색 눈 |
| `029.png` | 비정형 얼굴, 사용자 검수 방향 left |
| `reviewed.json` | 위 순서의 검수 완료 좌표와 볼 위치 |

PNG는 분석에 사용하는 원본이다. 크기를 바꾸거나 덮어쓰지 않는다.
JSON의 size와 각 PNG 크기가 일치해야 한다. 두 자료를 바꿀 때는 함께 검수해야 한다.
029는 위쪽 주요 얼굴을 분석하는 검수본이며 아래쪽 원은 눈 배열에 포함하지 않았다.

이 자료는 예시이지 정확도 평가용 정답 세트가 아니다. 같은 캐릭터 또는 같은 원본에서 생성된
다른 이미지도 평가용으로 사용하면 예시와 평가가 섞인다.
이미지가 많다고 정확도가 보장되는 것은 아니다. 6장 사용은 사용자의 확정 선택이다.

`app/face_analysis.py`가 크기·좌표·검수 상태를 확인해 읽고 캐시한다.
JSON을 수정한 뒤에는 서버를 재시작한다. 배포 패키지에는 PNG 6장과 JSON이 포함된다.
API 키는 여기에 저장하지 않고 `server/.env`에만 둔다.

자동 확인은 server 폴더에서 `pytest tests/test_face_analysis.py`로 실행한다.
실제 API 호출은 비용이 발생하므로 승인된 수동 확인에서만 실행한다.
